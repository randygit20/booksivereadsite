# Books I've Read 📚

A personal digital library documenting books I've read, capturing my thoughts, reflections, and takeaways from each reading experience.

## About the Project

Books I've Read is a personal reading archive designed to make it easy to explore books, revisit memorable reads, and keep track of my reading journey.

The project combines a clean interface with an organised presentation of books and their details.

## Features

- Browse a personal collection of books.
- View book covers and relevant information.
- Explore reading records in an organised layout.
- Enjoy a responsive interface across different screen sizes.
